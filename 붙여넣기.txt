이 폴더는 RISS 논문 다운로더 프로젝트다. 먼저 CLAUDE.md를 읽고 전체 맥락(구조,
설계 원칙, 실측으로 알아낸 RISS 지식)을 파악해라. 그리고 .claude/agents/ 에 있는
에이전트 팀(manager, developer, scholar)을 확인해라. 지금부터 이 팀으로 일한다.

## 내 상황
- 나는 "빈집(空家)" 주제로 박사논문을 준비 중이고 관련 문헌을 모으는 중이다.
- 광운대 도서관 프록시로 RISS를 쓴다. 이 도구는 다른 사람에게도 배포할 예정이다.
- 나는 개발자가 아니다. 명령어는 네가 직접 실행하고, 결과는 쉬운 말로 알려줘.
- 막히면 추측하지 말고 나에게 물어봐라.

## 반드시 지킬 원칙
1. 로그인은 내가 직접 한다. 코드가 비밀번호를 다루게 하지 마라.
2. 다운로드는 순차 유지(delay_sec). 병렬화하면 기관 계정이 차단될 수 있다.
3. stdout은 JSON 계약, 진행 로그는 stderr. 이 계약을 깨지 마라.
4. 셀렉터·URL 상수는 riss/selectors.py 에만 둔다.
5. 주석·커밋 메시지는 한국어로 쓴다.
6. 검증하지 않은 것을 "됐다"고 말하지 마라. 확인한 것과 추정을 구분해서 보고해라.

## 진행 순서

### 1단계 — 현재 상태 점검 [manager]
manager 에이전트로 다음을 확인하고 요약해줘:
- git 상태와 최신 커밋
- data/index.jsonl(검색된 수), data/metadata.jsonl(받은 수),
  data/failed.json(실패 수), data/diagnostics/(진단 파일 수), reference/(PDF 수)
- python -m py_compile app.py cli.py gui.py paths.py riss/*.py 로 문법 확인
끝나면 "다음 할 일"을 우선순위대로 알려줘.

### 2단계 — 실행 준비 (내가 로그인)
크롬이 9222 포트로 떠 있는지 확인하고, 없으면 아래로 띄워줘:
  chrome.exe --remote-debugging-port=9222 --user-data-dir=C:\chrome-riss https://kupis.kw.ac.kr/
띄운 뒤 "로그인하세요"라고 알려주고 멈춰라. 내가 "로그인 했어"라고 하면 진행해라.

### 3단계 — 검색 검증
python app.py search --keyword "빈집" --doctoral --fulltext
- 결과가 실제로 국내박사 학위논문만 나오는지 확인해줘.
  (학술지 목록이나 시집 같은 노이즈가 섞이면 필터가 안 먹는 것이니 원인을 찾아라)
- python app.py list 로 목록 확인

### 4단계 — 다운로드 검증
python app.py download --progress --all
- 성공/실패를 집계해줘
- reference/ 에 논문 제목으로 PDF가 저장되는지 확인
- config.json 이 생기지 않는지도 확인(안 생기는 게 정상)

### 5단계 — 실패 분석 및 수정 [developer]  ★핵심
developer 에이전트로:
- data/diagnostics/*.json 을 읽어 실패 원인을 제공처별로 분류해줘
  (교보스콜라 / DBpia / KISS / earticle / 기타)
- riss/download.py 와 riss/selectors.py 를 보강해 그 제공처도 받아지게 고쳐라
- 이미 두 전략이 있다: (a) 다운로드 버튼 클릭, (b) 응답 URL 감시 +
  ezPDF file= 디코딩 후 쿠키로 직접 GET. 이 둘로 왜 안 되는지 진단 파일로 판단해라
- 고친 뒤 실패분만 재시도: python app.py download --progress --retry-failed
- 검증되면 한국어 커밋 메시지로 커밋하고
  claude/dissertation-download-tool-boblze 브랜치에 push 해줘
  (push하면 GitHub Actions가 새 exe를 자동 빌드한다)

### 6단계 — 인용 기능 검증
- python app.py pdftext --id <받은논문id>   (텍스트가 나오는지)
- python app.py quote --id <id> --text "그 논문에 실제로 있는 문장"
- reference/annotated/ 에 밑줄 PDF가 생기는지 확인
- python app.py export --format korean
  (학위논문이 "대학 박사학위논문" 형식으로 나오는지 확인)

### 7단계 — 문헌 정리 [scholar]
scholar 에이전트로:
- 지금까지 받은 논문을 주제별로 분류해줘
  (발생원인 / 공간분석 / 법제도 / 세제 / 해외사례(일본) / 활용·재생 등)
- 내 주제(빈집)에서 놓친 검색어가 있으면 제안해줘
- 참고문헌 목록을 만들어줘: python app.py export --format korean --out reference/bibliography_korean.txt

## 보고 방식
각 단계가 끝날 때마다 결과를 짧게 요약하고, 다음 단계로 넘어가도 되는지 물어봐라.
브라우저 로그인처럼 내가 해야 하는 일은 나에게 시켜라.
